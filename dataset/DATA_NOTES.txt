Fresh Day — data preparation notes

Core dataset: Silva, Cristina (2024), ‘Hass’ Avocado Ripening Photographic Dataset, Mendeley Data V1, https://doi.org/10.17632/3xd9n945v8.1 (CC BY 4.0; cite original source). Original workbook provided by user, 14,722 rows, 478 unique (Storage Group, Sample) pairs.
Preparation: collapse duplicate observations with the same storage group, sample and experiment day; daily ripening classifications agree. For each fruit with an observed stage 5, take the first stage-5 day as endpoint; exclude 68 fruits with no observed stage-5 endpoint. From sorted (storage_group, sample as text) pairs, choose one earlier observation with stage 1–4 using Python random.Random(42).choice on sorted eligible days. Target = first stage-5 day minus chosen observation day. One row per fruit, 410 rows. This sampling is conditional on observed endpoints and may cause selection bias. Stage 5 = overripe; not a safety expiry date.
Features for the proposed model: storage_group (one-hot encode T10, T20, Tam) and ripening_stage (1–4). T10 = 10 C at 85% RH; T20 = 20 C at 85% RH; Tam = ambient conditions in study. These are not household refrigerator settings. fruit_id and experiment_day retained for audit only; do not use as features. No inference for other fruit types or unobserved storage conditions.
Preliminary audit (not final student project result): sklearn 1.8.0; split 80/20, random_state=42; 5-fold CV on training set. Linear regression CV R2 0.7756; decision tree max_depth=4 CV 0.8514; default RF 100 trees CV 0.8512; gradient boosting CV 0.8512. RF grid n_estimators=[50,100], max_depth=[3,5,None], min_samples_leaf=[1,3,5], random_state=42; best n_estimators=100,max_depth=5,min_samples_leaf=5; CV R2 0.8514; preliminary held-out R2 0.8656, RMSE 1.8951 days. Student should reproduce results; report actual results. Test results have been viewed during feasibility assessment; not a fresh external validation.
Other two tables: reference data only; not training data. FDA nutrient table is per listed edible serving, not per 100 g; vitamin C is published % daily value, not mg. Scale by actual edible grams divided by listed serving grams. Storage reference from University of Nebraska-Lincoln; missing values not zero; grouped foods and condition notes must be preserved. Reference durations not safety guarantees.
